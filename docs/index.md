# FFT Project Documentation

Welcome to the site. This page is the entry point for the documentation and the
best place to jump into the specific content areas.

Use the left-hand navigation menu to browse all documentation sections.

## Quick start

If you want to preview the docs locally:

```bash
mkdocs serve
```

If you want to check that the site builds cleanly without serving it:

```bash
mkdocs build --site-dir ./_site
```
